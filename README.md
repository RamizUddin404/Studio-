# RAMIZ STUDIO PRO

Free Bengali browser-based digital studio toolkit.

## Features
- Dashboard with local income/expense tracking and CSV export
- A4 passport photo layout
- NID front/back A4 print layout
- Images to printable PDF via browser print dialog
- Basic CV maker

## Run
Open `index.html` in a modern browser. No installation or paid API required.

## Hosting
For GitHub Pages: Settings → Pages → Deploy from a branch → main → root.

## Privacy
Images are processed locally in the browser. Accounts are saved to browser localStorage; export CSV backups regularly. Avoid sensitive ID documents on shared devices.

## Limitations
This is an MVP, not a complete Studiozly replica. No OCR, handwriting recognition, cloud sync, login, background removal, or customer database yet. Printing accuracy depends on browser and printer settings. Cross-browser tests have not yet been performed.

## Roadmap
Customer management, editing, OCR, tests, offline support and secure optional storage.
